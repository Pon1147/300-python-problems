# Bài 000: A + B - C

> **Chủ đề:** Nhập xuất cơ bản
> **Độ khó:** Easy
> **Số thứ tự:** 0

## Mô tả

Cho ba số nguyên a, b, c, hãy tính a + b - c và in kết quả ra màn hình.

## Yêu cầu

1. Đọc ba số nguyên từ bàn phím
2. Tính biểu thức a + b - c
3. In kết quả ra màn hình

## Input

- Dòng một: Một số nguyên a.
- Dòng hai: Hai số nguyên b và c, cách nhau bởi một dấu cách.
- Với -10 ≤ a, b, c ≤ 10.

## Output

- Một số nguyên duy nhất là kết quả của a + b - c.

## Ví dụ

**Input:**

```
3
5 2
```

**Output:**

```
6
```

## Gợi ý

- Sử dụng hàm `input()` để đọc dữ liệu
- Sử dụng `int()` để chuyển đổi sang số nguyên
- Sử dụng `map()` và `split()` để đọc nhiều số trên cùng một dòng

## Kiến thức cần biết

- Nhập dữ liệu từ bàn phím: `input()`
- Chuyển đổi kiểu: `int()`, `float()`
- In dữ liệu: `print()`
- Tách chuỗi thành danh sách: `str.split()`
- Áp dụng hàm cho từng phần tử: `map()`
