# Bài 001: Phép toán cộng

> **Chủ đề:** Phép toán cơ bản
> **Độ khó:** Easy
> **Số thứ tự:** 1

## Mô tả

Cho một số nguyên a, hãy tính tổng B = a + 2025 và in kết quả ra màn hình.

## Yêu cầu

1. Đọc một số nguyên a từ bàn phím
2. Tính B = a + 2025
3. In kết quả ra màn hình

## Input

- Một số nguyên a (|a| ≤ 10⁹).

## Output

- Một số nguyên duy nhất là kết quả của B.

## Ví dụ

**Input:**
```
10
```

**Output:**
```
2035
```

## Gợi ý

- Sử dụng toán tử `+` để cộng hai số nguyên
- Python hỗ trợ số nguyên lớn, không lo tràn số với |a| ≤ 10⁹

## Kiến thức cần biết

- Nhập dữ liệu: `int(input())`
- Toán tử cộng: `+`
- In kết quả: `print()`
