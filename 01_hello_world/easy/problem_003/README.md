# Bài 003: Phép toán nhân

> **Chủ đề:** Phép toán cơ bản
> **Độ khó:** Easy
> **Số thứ tự:** 3

## Mô tả

Cho một số nguyên a, hãy tính B = a × 3 và in kết quả ra màn hình.

## Yêu cầu

1. Đọc một số nguyên a từ bàn phím
2. Tính B = a × 3
3. In kết quả ra màn hình

## Input

- Một số nguyên a (|a| ≤ 10⁹).

## Output

- Một số nguyên duy nhất là kết quả của B.

## Ví dụ

**Input:**
```
4
```

**Output:**
```
12
```

## Gợi ý

- Sử dụng toán tử `*` để nhân hai số nguyên
- Python hỗ trợ số nguyên lớn, không lo tràn số

## Kiến thức cần biết

- Nhập dữ liệu: `int(input())`
- Toán tử nhân: `*`
- In kết quả: `print()`
