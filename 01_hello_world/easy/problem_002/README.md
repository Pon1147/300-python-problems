# Bài 002: Phép toán trừ

> **Chủ đề:** Phép toán cơ bản
> **Độ khó:** Easy
> **Số thứ tự:** 2

## Mô tả

Cho một số nguyên a, hãy tính B = a - 2 và in kết quả ra màn hình.

## Yêu cầu

1. Đọc một số nguyên a từ bàn phím
2. Tính B = a - 2
3. In kết quả ra màn hình

## Input

- Một số nguyên a (|a| ≤ 10⁹).

## Output

- Một số nguyên duy nhất là kết quả của B.

## Ví dụ

**Input:**
```
5
```

**Output:**
```
3
```

## Gợi ý

- Sử dụng toán tử `-` để trừ hai số nguyên

## Kiến thức cần biết

- Nhập dữ liệu: `int(input())`
- Toán tử trừ: `-`
- In kết quả: `print()`
